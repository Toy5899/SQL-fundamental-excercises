
# SQL Fundamentals Exercises

Throughout these exercises, I practiced writing SQL queries and solving different data-related problems using fundamental SQL techniques.

## 📚 Topics Covered

### 1. SQL Fundamentals

This section covers the basic building blocks of SQL, including:

* `SELECT`
* `FROM`
* `WHERE`
* `ORDER BY`
* `GROUP BY`
* `HAVING`
* `DISTINCT`
* Filtering and sorting data

### 2. Aggregate Functions

Aggregate functions are used to perform calculations on multiple rows and return a single result.

Topics covered include:

* `COUNT()`
* `SUM()`
* `AVG()`
* `MIN()`
* `MAX()`

### 3. CASE Statements

`CASE` statements are used to apply conditional logic in SQL queries.

The exercises include creating categories and labels based on specific conditions.

### 4. NULL Functions

This section focuses on handling missing or `NULL` values in a database.

Topics covered include:

* `IS NULL`
* `IS NOT NULL`
* `COALESCE()`
* `IFNULL()`

### 5. Date Functions and Date Math

These exercises focus on working with dates and performing date calculations.

Topics include:

* Extracting parts of a date
* Working with days, months, and years
* Calculating date differences
* Adding and subtracting dates
* Performing date calculations
